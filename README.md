# يلا رياضة | YALLA RIYADA

نسخة أولية ثابتة بـ HTML وCSS وJavaScript. لا تحتاج Node.js أو Git على الكمبيوتر.

## النشر على GitHub Pages
1. فك ضغط الملف على جهازك.
2. افتح مستودع GitHub واضغط Add file ثم Upload files.
3. ارفع الملفات الموجودة داخل المجلد، بما فيها مجلد assets، إلى جذر المستودع.
4. افتح Settings → Pages، واختر Deploy from a branch ثم main و /(root) ثم Save.

## الصفحات
index.html الرئيسية، matches.html المباريات، news.html الأخبار، assistant.html المساعد التجريبي، store.html المتجر.

## مهم
المباريات تجريبية، وقسم الأخبار والمتجر نماذج أولية. المساعد ليس متصلًا بخدمة ذكاء اصطناعي حقيقية. النتائج المباشرة وAI الحقيقي يحتاجان خدمات خارجية وربطًا آمنًا. لا تضع مفاتيح API سرية داخل GitHub Pages.
