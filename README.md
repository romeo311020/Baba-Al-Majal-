# يلا رياضة | YALLA RIYADA

منصة رياضية متعددة الألعاب باستخدام React + TypeScript + Vite. هذه نسخة أولية قابلة للتطوير، مع تنقل مستقل لكل صفحة عبر `HashRouter` لتناسب الاستضافة الثابتة مثل GitHub Pages.

## المتطلبات
- Node.js 20 أو أحدث
- npm

## التشغيل على Windows
1. فك ضغط ملف المشروع.
2. افتح مجلد `yalla-riyada` في VS Code.
3. افتح Terminal داخل المجلد.
4. نفّذ `npm install`.
5. نفّذ `npm run dev` وافتح الرابط المحلي الذي يظهر في الطرفية.
6. افحص نسخة الإنتاج عبر `npm run build` ثم `npm run preview`.

## الموجود في النسخة الحالية
- هوية SVG أصلية وشعار أفقي وأيقونة مربعة في `public/assets/brand/`.
- صفحة رئيسية، مباريات، تفاصيل مباراة، أخبار وتفاصيل خبر، صفحات الرياضات، متجر وتفاصيل منتج، Yalla AI، مفضلة، إشعارات، ملف شخصي، إعدادات، تسجيل/إنشاء حساب تجريبي، من نحن، اتصل بنا، الخصوصية، الشروط، وصفحة 404.
- تصميم RTL عربي متجاوب مع تبديل اتجاه أساسي للعربية والإنجليزية، مع حفظ اللغة والمفضلة في `localStorage`.
- بحث وفلترة في المباريات والأخبار والمتجر.
- بيانات تجريبية معلّمة بوضوح؛ لا توجد نتائج أو أسعار مباشرة.
- واجهة Yalla AI تجريبية فقط، لا تتصل بنموذج حقيقي.

## غير مفعّل بعد
- تسجيل الحسابات والمصادقة وقاعدة البيانات.
- مزود مباريات ونتائج مباشر، أو مصدر أخبار مرخّص.
- اتصال فعلي بنموذج ذكاء اصطناعي.
- تنبيهات Push، دفع إلكتروني، وروابط شراء من بائعين.
- روابط التواصل الرسمية.

## التكامل الآمن
- انسخ `.env.example` إلى `.env` لتوثيق إعدادات التطوير العامة فقط.
- لا تضع مفاتيح خاصة داخل متغيرات `VITE_*`؛ هذه القيم تُضمّن في كود المتصفح.
- أنشئ Backend/Serverless Function للمساعد الذكي ومزود الرياضة، وخزّن المفاتيح السرية في إعدادات الخادم، مع التحقق من المدخلات وتحديد معدل الطلبات.
- قبل النشر، راجع تراخيص الصور ومصادر الأخبار، وسياسة الخصوصية والشروط.

## ملاحظات
- `HashRouter` يجعل المسارات تعمل على الاستضافة الثابتة دون إعداد إعادة توجيه. المسار يظهر بصيغة `/#/matches`.
- لا يمكن منع تكبير الصفحة بشكل موثوق في جميع المتصفحات مع الحفاظ على إمكانية الوصول؛ لم يُستخدم تعطيل شامل للّمس أو الزوم.
- الصور الخارجية تحتاج اتصالًا بالإنترنت وقد تتغير أو تتوقف؛ استبدلها بأصول مرخّصة عند تجهيز الإطلاق.
